========================================
PROJECT DESCRIPTION
========================================

This project is a Student Management System
that stores and displays student details,
subjects, marks, percentage, and grades.

The project contains:

1. Backend using C++
2. Frontend using HTML, CSS, and JavaScript

The frontend provides an attractive interface
for entering student details.

The backend demonstrates Object Oriented
Programming concepts in C++.

========================================
FEATURES
========================================

✔ Add multiple students
✔ Enter subject names
✔ Enter marks student-wise
✔ Automatic total calculation
✔ Automatic percentage calculation
✔ Grade generation
✔ Student result cards
✔ Search by roll number (backend)
✔ Sorting students by percentage
✔ Exception handling
✔ Dynamic forms
✔ Attractive UI

========================================
HOW TO RUN FRONTEND
========================================

STEP 1:
--------
Open VS Code

STEP 2:
--------
Open frontend folder

STEP 3:
--------
Install "Live Server" extension

STEP 4:
--------
Right click on index.html

STEP 5:
--------
Click:
Open with Live Server

========================================
HOW TO RUN BACKEND
========================================

STEP 1:
--------
Open terminal in backend folder

STEP 2:
--------
Compile the code

Command:

g++ main.cpp -o main

STEP 3:
--------
Run the program

For Windows:

main.exe

For Mac/Linux:

./main
